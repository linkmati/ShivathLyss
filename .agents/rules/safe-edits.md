# Safe Editing & Revision Control Rules

## 1. Do Not Overwrite / Rewrite Notes Without Explicit Instruction
- NEVER rewrite, truncate, or replace existing note contents unless explicitly specified by the user.
- When expanding lore or adding imported information, append or make surgical additions while preserving existing user formatting, text, and structure.

## 2. Commit / Save Git State Before Modifying Files
- BEFORE making any code or file modifications in the workspace, ALWAYS create a git commit of current changes or save the git state so that previous file versions can be easily tracked, reviewed, or restored.
- REMINDER: NEVER run `git push` without explicit user permission.

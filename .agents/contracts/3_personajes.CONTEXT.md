# Shelf Contract: 3 - Personajes (Characters & Entities)

Record Library housing Player Character (PC) sheets/plans and Non-Player Character (NPC) dossiers.

## Structure
- `Jugadores/`: Player character sheets, abilities, personal goals, progression plans.
- `NPC/`: NPC dossiers, personality, allegiances, motivations, secrets.

## Context Boundary Rules
- **Load When**: Checking PC capabilities, planning PC advancement, looking up NPC relations/motives.
- **Do NOT Load**: Full DM combat files or unrequested NPC files.
- **Token Target**: 1k–3k tokens per character profile.

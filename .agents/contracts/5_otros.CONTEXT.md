# Shelf Contract: 5 - Otros (Mechanics, Magic & Systems)

Reference Library holding systemic rules, magic formulas, willpower rules, and campaign theories.

## Structure
- `Magic.md`: Magic system rules, spell mechanics, magical laws.
- `Voluntad.md`: Willpower / resolve system mechanics.
- `Mecanicas/`: Custom system rules, subsystems, combat rulings.
- `Teorías y preguntas.md`: World mysteries, cosmological theories, unresolved hypotheses.

## Context Boundary Rules
- **Load When**: Adjudicating spell interactions, checking custom rules, or researching cosmological mechanics.
- **Do NOT Load**: Specific NPC dossiers or DM adventure notes unless cross-referencing mechanics.
- **Token Target**: 2k–4k tokens.

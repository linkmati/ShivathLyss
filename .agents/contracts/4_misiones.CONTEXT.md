# Shelf Contract: 4 - Misiones (Player Mission Records)

Record Library housing played missions, ongoing quest journals, clues, and campaign progress from the player perspective.

## Structure
- Individual mission markdown files (e.g., `Arys Mission.md`, `Circles Below.md`, `Iron Vein + Crimson Fangs.md`, `Solipsis Initiation Ritual.md`, etc.).
- `Legacy/`: Archived past adventures and completed story milestones.

## Context Boundary Rules
- **Load When**: Reviewing past player achievements, clues discovered, or active player mission objectives.
- **Do NOT Load**: `7 - DM` files (DM spoilers, backend combat stats).
- **Token Target**: 1k–3k tokens per mission record.
